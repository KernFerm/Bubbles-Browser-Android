📲 Install the APK

Bubbles Browser is distributed through GitHub Releases. It is not currently listed in the Google Play Store.

  1. Download. Tap Download APK above using Chrome or another trusted Android browser.
  2. Open the file. Tap the completed download notification, or open it from the Files app.
  3. Allow this source. If Android asks, open Settings and temporarily allow installs from the browser or file manager you used.
  4. Install. Return to the installer, tap Install, and wait for Android to finish.
  5. Let Play Protect scan it. Keep Google Play Protect enabled. Install only the APK from this official repository and verify its checksum.
  6. Open Bubbles Browser. Grant only the optional permissions needed for notifications, nearby searches, local music, camera, or microphone.

Advanced Protection blocking installation?

Only if Android specifically blocks the APK, open Settings, search for Advanced Protection, and temporarily turn off Device protection. Install the verified APK, then return to the same screen and re-enable Device protection. Restart when Android requests it, and keep Google Play Protect enabled.

New app installation

Version 1.0.10 updates a compatible current installation. Install it over the existing app so Android retains local profiles and settings. Export important profile data before updating as an extra precaution.

🔒 Privacy you can inspect

Browser records stay on the device. Enabled privacy lists download automatically when no local cache exists, and the Trust Center separates ads, trackers, fingerprinting, malicious requests, cryptomining, and compatibility events.

Bubbles Browser contains no Ollama integration, generative AI, telemetry, analytics, or cloud synchronization.
